Hello,

Thank you for the review. A screen recording of Kvill running on macOS is
attached. It is unedited and shows the app from launch through to saving.

What the video shows, in order:

1. Opening a Markdown file from the Finder. The document appears formatted,
   with no project to create and nothing to import first.
2. Placing the cursor in a line. Kvill's one idea is that Markdown syntax sits
   in the left margin rather than in the text, dimmed, and returns exactly as
   typed when the cursor enters that line. The file on disk is never rewritten.
3. Ticking a task-list checkbox.
4. Pressing `/` for the insert menu and inserting a table.
5. Changing the colour scheme and the text size.
6. Opening a folder, which shows the Markdown files in it down the side of the
   window, and switching between two documents.
7. An image stored beside the document loading in place.
8. Saving.

Kvill is a plain document editor. It has no account, no in-app purchases, no
advertising and no server: the app ships without the network entitlement, so
macOS will not permit a connection at all. Nothing in it is hidden behind a
sign-in or a subscription, so there is no additional path for you to reach.

If there is a specific screen or behaviour you were unable to reach, please
tell me which one and I will send a recording of that on its own.
